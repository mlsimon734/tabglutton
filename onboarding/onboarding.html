Step 1 — Welcome

Tabglutton helps you tame a bloated tab bar with two tools:

  • Dedup closes exact-duplicate tabs.
  • Devour reads selected tabs through Defuddle, files each one into your Obsidian vault as a markdown note with frontmatter, then closes the tab.

This setup takes about 30 seconds and configures three things you'll otherwise have to chase down later.

You can revisit this walkthrough anytime from the extension's options page.

Step 2 — Obsidian vault

What's your Obsidian vault called? Open Obsidian → click the vault picker (cloud icon, bottom-left) → copy the exact name as it appears in the list. Capitalization and spaces matter.

Step 3 — Approve obsidian:// in your browser

Tabglutton hands clipped notes to Obsidian using the obsidian:// URL scheme. The first time your browser sees one, it asks permission to open the link with Obsidian.

You need to trigger that prompt now — otherwise it fires on every clip and Devour batches will stall waiting for you to approve each one. Click the test link below to send a harmless ping; it opens your vault in Obsidian and creates no note.

When the prompt appears, tick "Always allow this extension to open obsidian links" before clicking Open Link. Without that checkbox, the prompt re-fires every clip.

If nothing visible happens but Obsidian focuses, you've already approved obsidian:// previously — you're set.

Didn't see anything happen?

Some browsers (newer Zen builds in particular) suppress the prompt without surfacing it. To allow obsidian:// permanently:

  1. Go to about:preferences#general → scroll to Applications → set obsidian to Use Obsidian.
  2. If clips still silently fail, open about:config, search network.protocol-handler.warn-external.obsidian, and set it to false (create it as a Boolean if missing).
