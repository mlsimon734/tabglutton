Step 1 — Welcome

Tabglutton dedupes the tabs you've accumulated and clips the keepers into Obsidian as markdown notes with frontmatter. This setup takes about 30 seconds and configures three things you'll otherwise have to chase down later.

You can revisit this walkthrough anytime from the extension's options page.

Step 2 — Obsidian vault

What's your Obsidian vault called? Open Obsidian → click the vault picker (cloud icon, bottom-left) → copy the exact name as it appears in the list. Capitalization and spaces matter.

Step 3 — Approve obsidian:// in your browser

Tabglutton hands clipped notes to Obsidian using the obsidian:// URL scheme. The first time your browser sees one, it may ask permission to open the link with Obsidian.

Click below to send a harmless test — it opens your vault in Obsidian, no note is created. If a prompt appears, click Open Link to approve. If nothing visible happens but Obsidian focuses, you're already set.

Didn't see anything happen?

Some browsers (newer Zen builds in particular) suppress the prompt without surfacing it. To allow obsidian:// permanently:

  1. Go to about:preferences#general → scroll to Applications → set obsidian to Use Obsidian.
  2. If clips still silently fail, open about:config, search network.protocol-handler.warn-external.obsidian, and set it to false (create it as a Boolean if missing).
